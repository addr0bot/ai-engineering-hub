# Project Card Template RU

Шаблон для короткой русской карточки проекта.

## Карточка

```md
# Название Проекта

- Папка:
- Тема:
- Уровень:
- Формат:
- Local-first:
- Нужны API keys:
- Нужен GPU:

## Что Это
Коротко и без воды: что делает проект.

## Что Получится На Выходе
Какой результат пользователь увидит после запуска.

## Кому Подходит
Для кого этот проект полезен.

## Почему Стоит Открыть
В чем его реальная ценность внутри каталога.

## Что Может Сломаться
Самые вероятные проблемы: ключи, зависимости, GPU, нестабильный сервис, старые инструкции.

## Чем Можно Заменить Стек
Если проект завязан на неудобный или дорогой сервис, чем его упростить.

## Итог
Стоит ли брать проект первым, вторым или уже после базовых вещей.
```

## Минимальный Стандарт

Карточка должна отвечать на вопросы:

- что это за проект
- зачем он нужен
- какой результат даёт
- кому подходит
- что в нём может пойти не так
- чем заменить неудобные зависимости

## Чего Не Надо Делать

- не пересказывать весь upstream README
- не писать рекламный текст
- не скрывать ограничения
- не растягивать карточку на простыню
