# parlant-conversational-agent

- Папка: `parlant-conversational-agent`
- Тема: `agents / compliance`
- Уровень: `intermediate/advanced`
- Формат: `agent`
- Local-first: `частично`
- Нужны API keys: `необязательно`
- Нужен GPU: `необязательно`

## Что Это

Conversational agent на `Parlant`, заточенный под структурированный loan-approval flow. Проект показывает не просто свободный chat, а управляемый сценарий с этапами, правилами и handoff-логикой.

## Что Получится На Выходе

Агент, который проводит пользователя по фиксированному бизнес-процессу, вызывает tools и держит разговор в рамках нужной логики.

## Кому Подходит

- тем, кому интересны deterministic и compliance-driven агенты
- тем, кто работает с regulated domains
- тем, кто хочет посмотреть на stateful conversation, а не только на "задал вопрос -> получил ответ"

## Почему Стоит Открыть

Это хороший пример того, что полезные conversational systems часто строятся не как свободная болталка, а как сценарий с ограничениями и правилами. Для продуктового мышления это важнее, чем ещё один generic assistant.

## Что Может Сломаться

- проект полезен только если тебе действительно интересен structured business flow
- часть ценности здесь в доменной логике, а не в wow-эффекте модели
- запуск проще, чем у тяжёлых MCP-проектов, но понимание сценария требует большего внимания

## Чем Можно Заменить Стек

- если не нужен `Parlant`, ту же идею можно потом повторять на любом stateful agent framework
- если финансовая тема не нужна, смотреть на проект как на шаблон для любого compliance-sensitive use case

## Итог

Очень полезный неочевидный проект. Особенно для тех, кто хочет строить не просто AI-chat, а управляемые продуктовые сценарии.
