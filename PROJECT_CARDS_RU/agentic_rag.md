# agentic_rag

- Папка: `agentic_rag`
- Тема: `agents / RAG`
- Уровень: `intermediate`
- Формат: `app`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `желательно`

## Что Это

Agentic RAG на `CrewAI`: проект умеет искать по документам и при необходимости уходить во внешний web search. Есть локальный путь с `DeepSeek` или `Llama 3.2`, но для web fallback нужен `FireCrawl API key`.

## Что Получится На Выходе

Приложение, которое уже ведёт себя не как простой document chat, а как более составная система с агентной логикой и внешними инструментами.

## Кому Подходит

- тем, кто уже понял обычный RAG
- тем, кто хочет перейти к агентным сценариям
- тем, кому интересно, как соединяются retrieval, tools и orchestration

## Почему Стоит Открыть

Это хороший следующий шаг после базового RAG. Проект показывает, где заканчивается обычный retrieval pipeline и начинается более сложное агентное поведение.

## Что Может Сломаться

- нужен `FireCrawl API key`
- больше зависимостей, чем у простых RAG-проектов
- сложнее отлаживать, потому что здесь уже несколько уровней логики

## Чем Можно Заменить Стек

- если web fallback не нужен, сначала упрощать сценарий до локального agentic RAG без внешнего web search
- если `CrewAI` кажется тяжёлым, потом можно повторить тот же паттерн на другом агентном фреймворке

## Итог

Брать не первым, а после `simple-rag-workflow` или `document-chat-rag`. Один из самых полезных проектов для перехода от базового RAG к агентам.
