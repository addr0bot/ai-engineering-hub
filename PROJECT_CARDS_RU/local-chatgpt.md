# local-chatgpt

- Папка: `local-chatgpt`
- Тема: `local LLM UI`
- Уровень: `beginner`
- Формат: `app`
- Local-first: `да`
- Нужны API keys: `нет`
- Нужен GPU: `желательно`

## Что Это

Локальный чат-интерфейс на `Chainlit` и `Ollama`. Проект поднимает простой ChatGPT-подобный UI без облачного API и без сложной инфраструктуры.

## Что Получится На Выходе

Рабочее локальное приложение, в котором можно общаться с моделью через браузерный интерфейс.

## Кому Подходит

- тем, кто хочет быстрый и наглядный первый результат
- тем, кому важен local-first сценарий
- тем, кто хочет получить UI, а не только notebook

## Почему Стоит Открыть

Это один из самых прямых путей от "хочу локальный ИИ" к реальной демке. Для вайбкодерской аудитории польза считывается сразу.

## Что Может Сломаться

- не установлен или не запущен `Ollama`
- не скачана модель `llama3.2-vision`
- на слабой машине ответ будет медленным, особенно с vision-моделью

## Чем Можно Заменить Стек

- если vision не нужен, взять более лёгкую text-only модель в `Ollama`
- если не нужен `Chainlit`, потом переносить логику в `Streamlit` или свой frontend

## Итог

Брать одним из первых. Это хороший стартовый проект для тех, кому нужен локальный UI, а не теория про LLM.
