# document-chat-rag

- Папка: `document-chat-rag`
- Тема: `RAG`
- Уровень: `beginner/intermediate`
- Формат: `app`
- Local-first: `частично`
- Нужны API keys: `нет`
- Нужен GPU: `желательно`

## Что Это

RAG-приложение для чата с документами на локальной модели `Llama 3.3`, `Streamlit` и `Qdrant`.

## Что Получится На Выходе

Интерфейс, в котором можно загрузить или проиндексировать документы и задавать по ним вопросы через чат.

## Кому Подходит

- тем, кто уже понял базовый RAG и хочет более прикладной сценарий
- тем, кому нужен первый нормальный `chat with docs` use case
- тем, кто хочет посмотреть связку `Streamlit + vector DB + local model`

## Почему Стоит Открыть

Это хороший переход от учебного notebook к более привычному приложению. Проект ближе к тому, что люди реально хотят собрать первым практическим RAG-сервисом.

## Что Может Сломаться

- `Llama 3.3` может оказаться тяжёлой для слабой машины
- `Qdrant` нужно отдельно поднять через `Docker`
- у человека может не быть ресурсов для комфортного local run

## Чем Можно Заменить Стек

- тяжёлую модель можно заменить на более лёгкую локальную
- `Qdrant` можно оставить, но для первых экспериментов подойдёт и более простой local vector store
- если нужен совсем простой старт, сначала идти в `simple-rag-workflow`

## Итог

Брать вторым шагом после базового RAG. Сильный проект для тех, кто хочет не теорию, а уже понятный пользовательский сценарий.
