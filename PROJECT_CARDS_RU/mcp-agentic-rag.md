# mcp-agentic-rag

- Папка: `mcp-agentic-rag`
- Тема: `MCP / agents`
- Уровень: `intermediate/advanced`
- Формат: `server + notebook`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `нет`

## Что Это

Agentic RAG-сценарий с `MCP`, `Qdrant` и web scraping через `Bright Data`. Проект связывает локальную векторную базу, внешний поиск и MCP-подключение к `Cursor`.

## Что Получится На Выходе

Локальный MCP-сервер, который умеет работать с векторной базой и при необходимости ходить во внешний веб.

## Кому Подходит

- тем, кто уже понял обычный RAG и хочет перейти к MCP-сценариям
- тем, кто собирает AI tooling вокруг `Cursor`
- тем, кому интересна связка `Qdrant` + web fallback + MCP

## Почему Стоит Открыть

Проект хорошо показывает, что `MCP` полезен не только для абстрактных демо, а для конкретной интеграции инструментов и retrieval-логики в рабочую IDE-среду.

## Что Может Сломаться

- нужен `Bright Data` account и credentials
- нужен `Docker` для `Qdrant`
- есть ручная настройка `Cursor MCP`, которая сама по себе может занять время

## Чем Можно Заменить Стек

- если `Bright Data` избыточен, сначала упростить до локального retrieval без web fallback
- если не нужен `Cursor`, использовать ту же идею с другим MCP-клиентом

## Итог

Брать после знакомства с `cursor_linkup_mcp` или базовым agentic RAG. Проект полезный, но явно не для первого захода.
