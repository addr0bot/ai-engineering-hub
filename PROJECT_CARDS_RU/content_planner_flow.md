# content_planner_flow

- Папка: `content_planner_flow`
- Тема: `agents / content`
- Уровень: `intermediate`
- Формат: `workflow`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `необязательно`

## Что Это

Агентный workflow на `CrewAI Flow`, который скрапит сайт, готовит соцпост и может отправить его дальше через publishing-сервис.

## Что Получится На Выходе

Автоматизированная цепочка "забрать контент -> превратить в пост -> подготовить к публикации", а не просто чат с моделью.

## Кому Подходит

- тем, кто хочет смотреть на AI не как на чат, а как на автоматизацию контент-задач
- тем, кто собирает internal tools и небольшие маркетинговые пайплайны
- тем, кому интересны agentic workflows с прикладным результатом

## Почему Стоит Открыть

Проект быстро объясняет, зачем вообще нужны workflow-агенты. Польза считывается сразу: это не абстрактная демка, а понятный pipeline под реальную задачу.

## Что Может Сломаться

- нужен `Firecrawl API key`
- нужен `Typefully API key`
- local LLM path есть, но внешний publish/web слой всё равно привязан к сервисам

## Чем Можно Заменить Стек

- если не нужен `Typefully`, оставить только подготовку поста без публикации
- если не нужен `CrewAI`, потом повторить ту же идею на более простом orchestration-слое

## Итог

Хороший проект после базовых RAG и chat-apps. Особенно полезен тем, кто думает в сторону реальной автоматизации, а не только демо.
