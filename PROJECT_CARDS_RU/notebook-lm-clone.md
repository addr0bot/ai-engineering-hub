# notebook-lm-clone

- Папка: `notebook-lm-clone`
- Тема: `product-style RAG`
- Уровень: `advanced`
- Формат: `app`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `желательно`

## Что Это

Открытая реализация `NotebookLM`-подобного продукта: загрузка документов, ответы с цитированием, память диалога, работа с разными форматами и генерация AI-подкастов.

## Что Получится На Выходе

Большое `Streamlit`-приложение, которое выглядит уже не как учебный notebook, а как продуктовый knowledge assistant.

## Кому Подходит

- тем, кто хочет изучить RAG-систему ближе к продакшен-формату
- тем, кому интересны citation-first интерфейсы
- тем, кто хочет посмотреть на связку ingestion, retrieval, memory и UI в одном проекте

## Почему Стоит Открыть

Это один из самых насыщенных проектов каталога. Он полезен не как первый шаг, а как обзор того, во что превращается RAG, когда его собирают как продукт, а не как демо.

## Что Может Сломаться

- много внешних зависимостей: `OpenAI`, `AssemblyAI`, `Firecrawl`, `Zep`
- больше точек отказа, чем у простых проектов
- инфраструктура тяжелее, запуск дольше, отладка заметно сложнее

## Чем Можно Заменить Стек

- сначала вырезать audio, podcast и web ingestion, оставив только документы
- заменить часть облачных сервисов на local-first аналоги, если цель не повторить весь стек целиком

## Итог

Брать уже после базовых и средних RAG-проектов. Хороший проект для разбора архитектуры, но плохой кандидат на самый первый запуск.
