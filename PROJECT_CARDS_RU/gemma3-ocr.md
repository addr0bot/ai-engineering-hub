# gemma3-ocr

- Папка: `gemma3-ocr`
- Тема: `OCR`
- Уровень: `beginner`
- Формат: `app`
- Local-first: `да`
- Нужны API keys: `нет`
- Нужен GPU: `желательно`

## Что Это

Локальное OCR-приложение на `Streamlit` и `Ollama`, которое использует vision-модель `Gemma 3` для извлечения текста и приведения его к аккуратному Markdown-формату.

## Что Получится На Выходе

Простая демка, куда можно загрузить картинку и сразу получить структурированный текст в браузере.

## Кому Подходит

- тем, кто хочет быстрый visual result
- тем, кому нужен local-first OCR без облачных API
- тем, кто хочет наглядный проект для первого или второго запуска

## Почему Стоит Открыть

Это очень понятный и быстрый сценарий. Загрузка картинки, ответ модели и видимый результат делают проект хорошей точкой входа для широкой аудитории.

## Что Может Сломаться

- не установлен `Ollama`
- не загружена модель `gemma3:12b`
- на слабой машине OCR будет медленным

## Чем Можно Заменить Стек

- если `Gemma 3` тяжеловата, пробовать более лёгкие vision-модели
- если нужен только сырой OCR без LLM-обработки, можно потом сравнить с классическими OCR-инструментами

## Итог

Брать одним из первых local-first проектов. Особенно полезен для тех, кому важен быстрый и понятный визуальный результат.
