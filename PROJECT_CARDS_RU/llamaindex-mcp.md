# llamaindex-mcp

- Папка: `llamaindex-mcp`
- Тема: `MCP`
- Уровень: `intermediate`
- Формат: `client + server`
- Local-first: `да`
- Нужны API keys: `необязательно`
- Нужен GPU: `необязательно`

## Что Это

Локальный `MCP`-клиент на `LlamaIndex`, который умеет подключаться к локальному `MCP`-серверу и вызывать инструменты через natural language.

## Что Получится На Выходе

Рабочая схема `MCP client -> MCP server -> tool`, которую можно гонять у себя на машине без обязательной привязки к облаку.

## Кому Подходит

- тем, кто хочет понять `MCP` не через IDE, а на более низком уровне
- тем, кому интересен локальный tool-calling pipeline
- тем, кто хочет руками увидеть, как агент работает с инструментами

## Почему Стоит Открыть

Это один из самых чистых проектов для понимания самой механики `MCP`. Здесь меньше шума вокруг продукта и больше пользы для инженерного понимания.

## Что Может Сломаться

- нужно отдельно поднять локальный `MCP`-сервер
- можно запутаться между разными клиентскими сценариями
- если запускать через local model path, качество и скорость будут зависеть от машины

## Чем Можно Заменить Стек

- если не нужен `LlamaIndex`, потом повторить тот же паттерн на другом агентном слое
- если не нужен `OpenAI`, оставаться на `Ollama` и полностью локальном сценарии

## Итог

Очень хороший проект для тех, кто хочет реально понять `MCP`, а не просто видеть его в обертке `Cursor`.
