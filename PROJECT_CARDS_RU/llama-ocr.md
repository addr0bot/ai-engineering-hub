# llama-ocr

- Папка: `llama-ocr`
- Тема: `OCR`
- Уровень: `beginner`
- Формат: `app`
- Local-first: `да`
- Нужны API keys: `нет`
- Нужен GPU: `желательно`

## Что Это

Локальное OCR-приложение на `Llama 3.2 vision` и `Streamlit`. Показывает простой и наглядный сценарий извлечения текста из изображений без обязательного облачного OCR.

## Что Получится На Выходе

Запускаемое приложение, в котором можно подать изображение и получить текстовый результат.

## Кому Подходит

- тем, кто хочет быстрый визуальный результат
- тем, кому интереснее OCR и vision, чем чат
- тем, кто ищет local-first проект без обязательных платных API

## Почему Стоит Открыть

Один из самых наглядных стартовых проектов в репозитории. Полезен тем, что результат видно сразу, а сама идея понятна без долгого объяснения.

## Что Может Сломаться

- не поднят `Ollama`
- не скачана vision-модель
- слабая машина может медленно обрабатывать изображения

## Чем Можно Заменить Стек

- вместо `Llama 3.2 vision` можно пробовать другие локальные vision-language модели
- если нужен более структурированный вывод, стоит посмотреть `gemma3-ocr` и `qwen-2.5VL-ocr`

## Итог

Один из лучших первых проектов для форка. Особенно хорош для аудитории, которой важен быстрый и понятный результат.
