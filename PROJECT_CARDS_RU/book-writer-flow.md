# book-writer-flow

- Папка: `book-writer-flow`
- Тема: `agents / longform generation`
- Уровень: `advanced`
- Формат: `workflow`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `необязательно`

## Что Это

Agentic workflow для автоматической сборки книги: проект использует `CrewAI`, `Bright Data` и `Gemma 3`, чтобы собирать материалы и превращать их в длинный итоговый текст.

## Что Получится На Выходе

Сгенерированный longform-артефакт уровня мини-книги, а не одиночный ответ модели.

## Кому Подходит

- тем, кто хочет посмотреть на multi-step content generation
- тем, кому интересны длинные agentic pipelines
- тем, кто хочет разбирать не чат, а процесс производства большого текста

## Почему Стоит Открыть

Проект показывает важную идею: агентные системы полезны не только для Q&A, но и для длинных производственных сценариев, где нужен сбор источников и поэтапная генерация.

## Что Может Сломаться

- нужен `Bright Data` account и credentials
- структура запуска не самая простая: вложенные папки, `.env`, отдельная точка входа
- quality longform-результата будет сильно плавать

## Чем Можно Заменить Стек

- если `Bright Data` не нужен, сначала тестировать тот же паттерн на заранее подготовленных материалах
- если не нужен именно book-scale output, упрощать до outline/article workflow

## Итог

Брать не первым. Полезный проект для понимания длинных агентных пайплайнов, но с заметным инфраструктурным трением.
