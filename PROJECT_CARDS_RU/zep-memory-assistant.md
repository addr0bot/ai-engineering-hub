# zep-memory-assistant

- Папка: `zep-memory-assistant`
- Тема: `agents / memory`
- Уровень: `intermediate`
- Формат: `app`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `необязательно`

## Что Это

AI-ассистент с долговременной памятью на `Zep`, агентной логикой через `AutoGen` и UI на `Streamlit`. Модельный путь можно держать локально через `Ollama`, но память вынесена во внешний сервис.

## Что Получится На Выходе

Чат-приложение, в котором агент запоминает факты о пользователе и может использовать их в следующих сообщениях и сессиях.

## Кому Подходит

- тем, кто хочет понять тему memory layer у агентов
- тем, кому интересно, как агентные системы делают персонализацию
- тем, кто уже прошёл обычные chat-apps и хочет следующий уровень

## Почему Стоит Открыть

Проект закрывает важную тему, которой часто не хватает в базовых демках: память между разговорами. Это полезный мост между "LLM отвечает" и "агент действительно помнит контекст пользователя".

## Что Может Сломаться

- нужен `Zep API key`
- есть несколько движущихся частей: `AutoGen`, `Zep`, `Ollama`, `Streamlit`
- качество сценария зависит не только от модели, но и от того, как память реально записывается и извлекается

## Чем Можно Заменить Стек

- если не нужен `Zep`, сначала собирать упрощённую память локально
- если `AutoGen` кажется тяжёлым, потом повторить идею памяти на другом агентном фреймворке

## Итог

Хороший проект после базовых агентов и RAG. Не стартовый, но очень полезный для понимания, как устроена память в более серьёзных AI-сценариях.
