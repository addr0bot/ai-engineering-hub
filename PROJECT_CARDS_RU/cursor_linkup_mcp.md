# cursor_linkup_mcp

- Папка: `cursor_linkup_mcp`
- Тема: `MCP`
- Уровень: `intermediate`
- Формат: `server`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `нет`

## Что Это

Кастомный `MCP`-сервер для `Cursor`, который добавляет deep web search через `Linkup` и RAG-логику на `LlamaIndex`.

## Что Получится На Выходе

Рабочий MCP-инструмент, который можно подключить к `Cursor` и использовать как внешний источник поиска и контекста.

## Кому Подходит

- тем, кто уже трогал `Cursor` и хочет понять практику `MCP`
- тем, кому интересны tool integrations, а не только chat UI
- тем, кто собирает dev-tooling вокруг AI IDE

## Почему Стоит Открыть

Проект полезен не как "ещё один агент", а как конкретный мост между IDE, внешним поиском и RAG. Для темы `MCP` это одна из самых понятных точек входа.

## Что Может Сломаться

- нужен `LINKUP_API_KEY`
- нужен `OPENAI_API_KEY`
- сама тема `MCP` быстро меняется, поэтому интеграционные детали могут устаревать

## Чем Можно Заменить Стек

- если не нужен `Linkup`, можно строить тот же паттерн на другом search API
- если не нужен `OpenAI`, retrieval-часть потом можно упростить или перевести на local model path

## Итог

Брать после базового знакомства с RAG и LLM apps. Хороший проект, чтобы понять, как AI IDE подключают внешние инструменты через `MCP`.
