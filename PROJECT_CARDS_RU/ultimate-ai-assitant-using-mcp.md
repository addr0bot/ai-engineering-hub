# ultimate-ai-assitant-using-mcp

- Папка: `ultimate-ai-assitant-using-mcp`
- Тема: `MCP / multi-tool`
- Уровень: `advanced`
- Формат: `app`
- Local-first: `частично`
- Нужны API keys: `да`
- Нужен GPU: `нет`

## Что Это

`Streamlit`-приложение, которое подключает несколько `MCP`-серверов сразу и даёт единый chat-интерфейс для работы с браузером, scraping, RAG, memory, terminal и другими инструментами.

## Что Получится На Выходе

Multi-tool assistant, который показывает, как один AI-интерфейс можно связать с целым набором `MCP`-инструментов вместо одного узкого сценария.

## Кому Подходит

- тем, кто хочет собрать "швейцарский нож" на MCP
- тем, кому интересны orchestration и конфигурация нескольких серверов сразу
- тем, кто хочет смотреть на MCP как на платформенный слой, а не на отдельный тул

## Почему Стоит Открыть

Проект хорошо показывает потолок сложности у MCP-подхода. Это уже не демо одного сервера, а конструктор целой AI-среды с несколькими возможностями.

## Что Может Сломаться

- много внешних зависимостей и ключей
- нужно руками править пути к MCP-серверам
- рост числа серверов быстро усложняет отладку и поддержку

## Чем Можно Заменить Стек

- если такой набор слишком тяжёлый, начинать с 1-2 MCP-серверов, а не со всего набора
- если не нужен `Streamlit`, использовать этот проект как reference по конфигурации и архитектуре
