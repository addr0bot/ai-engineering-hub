## Зачем Нужны Карточки

Обычный upstream README отвечает не на все практические вопросы. Карточки нужны, чтобы быстро понять:

- что это за проект
- какой будет результат
- кому он подходит
- что в нём может сломаться
- чем заменить неудобный стек
