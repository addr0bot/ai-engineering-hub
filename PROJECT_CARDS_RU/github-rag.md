# github-rag

- Папка: `github-rag`
- Тема: `RAG / code`
- Уровень: `beginner/intermediate`
- Формат: `app`
- Local-first: `да`
- Нужны API keys: `необязательно`
- Нужен GPU: `необязательно`

## Что Это

Локальное RAG-приложение для работы с GitHub-репозиториями. Использует `GitIngest` для преобразования репозитория в удобный текстовый формат и `LlamaIndex` для RAG-оркестрации.

## Что Получится На Выходе

Приложение, через которое можно задавать вопросы по репозиторию как по базе знаний.

## Кому Подходит

- разработчикам
- тем, кто хочет применить RAG к коду, а не к обычным документам
- тем, кому нужен сценарий ближе к повседневной инженерной пользе

## Почему Стоит Открыть

Этот проект сильно ближе к практической разработке, чем обычные document-chat демки. Для технической аудитории польза считывается сразу.

## Что Может Сломаться

- путаница между local path и GitHub source
- optional интеграция с `OpenAI` может отвлекать от local-first сценария
- качество ответов зависит от того, насколько хорошо репозиторий был преобразован в текст

## Чем Можно Заменить Стек

- если не нужен `OpenAI`, оставаться на local path через `Ollama`
- при необходимости retrieval можно упростить до более простого local pipeline

## Итог

Очень хороший проект для аудитории разработчиков. Логично открывать после базового RAG или сразу, если цель именно работа с кодовой базой.
