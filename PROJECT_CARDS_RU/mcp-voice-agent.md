# mcp-voice-agent

- Папка: `mcp-voice-agent`
- Тема: `MCP / voice`
- Уровень: `advanced`
- Формат: `agent`
- Local-first: `нет`
- Нужны API keys: `да`
- Нужен GPU: `нет`

## Что Это

Голосовой агент с `MCP`, который совмещает web search, голосовой ввод-вывод и работу с `Supabase` через MCP-интеграцию.

## Что Получится На Выходе

Сложный voice-agent сценарий: пользователь говорит голосом, агент обрабатывает речь, ходит в веб, может работать с базой и отвечает обратно голосом.

## Кому Подходит

- тем, кто уже перерос простые chat-apps
- тем, кому интересны real-time voice pipelines
- тем, кто хочет посмотреть на `MCP` в более насыщенном интеграционном сценарии

## Почему Стоит Открыть

Проект полезен как ориентир по сложным AI integrations. Здесь сразу видно, сколько внешних слоёв появляется, когда делаешь не текстовый чат, а voice-agent с внешними сервисами.

## Что Может Сломаться

- нужен длинный список ключей и credentials: `Firecrawl`, `Supabase`, `OpenAI`, `AssemblyAI`, `LiveKit`
- проект сильно зависит от внешней инфраструктуры
- отладка сложнее, потому что ошибки могут быть в speech, MCP, web search или real-time канале

## Чем Можно Заменить Стек

- сначала выкинуть voice и оставить только MCP + text agent
- если не нужен `Supabase`, оставить только retrieval/search сценарий
- если цель local-first, этот проект лучше брать как референс, а не как первый запуск
