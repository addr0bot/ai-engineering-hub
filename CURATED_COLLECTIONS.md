## How To Use This File

- Start by picking one collection based on the outcome you want, not the model name that happens to be trending.
- Add a short Russian card for every project you decide to promote publicly.
- Prefer projects with clear setup instructions, visible output, and a believable one-evening success path.
- Mark expensive, fragile, or region-dependent projects explicitly so the repository stays trustworthy for a RU audience.
